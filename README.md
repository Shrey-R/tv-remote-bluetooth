# TV Remote (Bluetooth)

A Bluetooth-only remote page for our Android TV, for a Web Bluetooth browser:
[Bluefy](https://apps.apple.com/app/bluefy-web-ble-browser/id1492822055) on iPhone, Chrome on Android.

Bookmark this page. It checks whether the TV answers over Wi-Fi: if it does, it opens the full remote on the TV; if it
doesn't, it stays as a Bluetooth rescue remote (connect, Power, turn the TV's Wi-Fi on, basic keys) and opens the full
remote by itself once the TV is back. Hosted here so it opens over any internet connection, even when the TV is off
Wi-Fi. Add `?stay=1` to stay on this page.

Only phones already paired with the TV can send commands: pairing needs a code confirmed on the TV with its remote.
