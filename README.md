# TV Remote (Bluetooth)

A Bluetooth-only remote page for our Android TV, for a Web Bluetooth browser:
[Bluefy](https://apps.apple.com/app/bluefy-web-ble-browser/id1492822055) on iPhone, Chrome on Android.

It talks to the TV only over Bluetooth Low Energy (the TV's home-screen app runs a small BLE service), so it works when
the TV is off Wi-Fi. Hosted here so the page itself opens over any internet connection.

Only phones already paired with the TV can send commands: pairing needs a code confirmed on the TV with its remote.
